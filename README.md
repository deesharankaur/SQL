# 🗄️ CS50's Introduction to Databases with SQL (CS50SQL)

Welcome to my repository for **CS50’s Introduction to Databases with SQL**! This repository serves as a portfolio of my work, documenting my journey through Harvard University’s rigorous database course. Each week's problem set has been solved, organized, and optimized to demonstrate practical database design and query execution skills.

---

## 🚀 About the Course
[CS50 SQL](https://cs50.harvard.edu/sql/) dives deep into how to design, query, and manage relational databases. Throughout this curriculum, I gained hands-on experience with:
*   Relational database concepts and entity-relationship (ER) modeling.
*   Writing complex SQL queries (`SELECT`, `JOIN`, `GROUP BY`, subqueries).
*   Database design principles, schema optimization, and normalization (1NF, 2NF, 3NF).
*   Performance tuning, indexes, and concurrency control.
*   Writing database-driven applications and integrating Python with SQL databases.
